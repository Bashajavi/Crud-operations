**Project Overview**
The Task Manager application is a web-based solution designed to help manage tasks efficiently. It provides features for creating, reading, updating, and deleting tasks (CRUD operations) along with a user-friendly interface.

**Technology Stack**
Java: Backend programming language.
Spring Boot: Framework for building RESTful APIs.
MySQL: Database for storing task-related data.
Bootstrap: Frontend framework for responsive design.
IntelliJ IDEA: IDE used for development.

**Features**
Create Task: Allows users to add new tasks by providing relevant details.
Read Tasks: Displays the list of existing tasks.
Update Task: Enables users to edit task details.
Delete Task: Allows removal of tasks.

**Server Configuration**
Port: 8080 for accessing the application.
